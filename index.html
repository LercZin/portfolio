How I think

Cómo pienso

Problems I have solved

Problemas que he resuelto

01 · Pinheiro Móveis

A store must never see another store's data.

Una tienda nunca debe ver los datos de otra.

Store scope enforced on the server, on every query and on creation, with tests that try to read another store's customer by ID.El ámbito de tienda se aplica en el servidor, en cada consulta y al crear, con pruebas que intentan leer por ID un cliente de otra tienda.
02 · Pinheiro Móveis

A stock count that fails halfway must not leave half the stock adjusted.

Un recuento que falla a mitad no puede dejar medio inventario ajustado.

One transaction with row locks, rejected if the balance changed since counting started.Una transacción con bloqueo de filas, rechazada si el saldo cambió desde que empezó.
03 · Viure

Payment providers repeat notifications, sometimes before the charge exists.

Los proveedores de pago repiten avisos, a veces antes de que exista el cobro.

Each event is stored, applied once and replayed when the matching payment appears.Cada evento se guarda, se aplica una vez y se reprocesa cuando aparece el pago.
04 · Viure

A retried checkout must not charge twice.

Repetir un checkout no debe cobrar dos veces.

One attempt key kept through network failures; the flow stops instead of silently creating a new charge.Una única clave de intento ante fallos de red; el flujo se detiene en vez de crear otro cobro.
05 · Cérebro

Tenant isolation should not depend on remembering a WHERE clause.

El aislamiento no debería depender de acordarse de un WHERE.

PostgreSQL row-level security: the database refuses another company's rows.Row-level security de PostgreSQL: la base de datos rechaza las filas de otra empresa.
06 · Cérebro

Uploaded spreadsheets are hostile input.

Las hojas de cálculo subidas son entradas hostiles.

Parsed in a worker with macros and external links off; bad rows quarantined with a reason, exports guarded against formula injection.Se procesan en un worker sin macros ni enlaces externos; las filas inválidas van a cuarentena y las exportaciones se protegen contra inyección de fórmulas.
